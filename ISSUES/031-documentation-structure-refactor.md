# Issue 031 — Merapikan struktur dokumentasi

Status: Selesai

## Tujuan

Membuat README ringkas dan memindahkan penjelasan teknis ke dokumentasi yang
terorganisasi berdasarkan topik.

## Perubahan

- README diringkas menjadi overview, quick start, fitur utama, dan indeks
  dokumentasi.
- Menambahkan `docs/deployment.md` untuk deployment dan migration.
- Menambahkan `docs/bot-behavior.md` untuk perilaku bot.
- Menambahkan `docs/configuration.md` untuk credential dan state.
- Menambahkan `docs/development.md` untuk pengembangan dan validasi.
- Mempertahankan histori perubahan di folder `ISSUES/`.

## File terkait

- `README.md`
- `docs/deployment.md`
- `docs/bot-behavior.md`
- `docs/configuration.md`
